# Quality check against the 10 rules (2026-11-01)

Checked on 2026-11-14, when M1 was built, on Windows 11 with Temurin 21.0.12.1, Maven 3.9.11,
Python 3.14.5 and Node.js 24.19.0. The code is pure computation plus reading the shared vector
files and one generator (`spec/generate_vectors.py`).

## Rules

| # | Rule | Status | Evidence |
|---|---|---|---|
| 1 | Assume every call can fail | pass | No network or service calls. File reads (`vectors.py` `load`, `Vectors.load`, `vectors.js` `load`) turn missing, unreadable and oversized files into `VectorError` with the path; each CLI maps it to exit code 1 (`test_missing_vectors_dir`, `cliErrors`, JS `cli report fails…`). No empty `catch`/`except`: JS `moneyCase` rethrows anything that is not a `MoneyError`; ruff `BLE`, `S110`, `E722` are enabled. |
| 2 | Writes safe to retry | pass | The only writer is the generator: `write_atomic` writes a temp file in the target directory and `os.replace`s it; re-running gives identical files (`--check` exits 0). `test_write_atomic_replaces_whole_file`, `test_check_detects_drift_and_write_repairs_it`. |
| 3 | No race conditions | pass | No threads or async code. `Money` is immutable in every language (Java record, frozen dataclass, frozen JS object with private fields: `instances are immutable`). The JS `DataView` scratch buffer is module-level but only used synchronously inside one call. |
| 4 | Don't trust the clock | N/A | No durations or timestamps are measured or stored. |
| 5 | Read before changing | pass | No environment variables are read by the code. One JVM system property, `fpm.vectors`, is documented in the README and set by `pom.xml`. APIs used exist in the installed versions (`Math.addExact`, `Double.doubleToRawLongBits`, `math.ulp`, `DataView.getBigUint64`, `Object.hasOwn`). Every README path exists (`audit_repo.py` checks links). |
| 6 | Never break compatibility | pass | New repository. Vector file formats are documented in each file's header; the canonical text form (`12.34 USD`) and error kinds are the same in all three languages. |
| 7 | One source of truth | pass | `doubles.tsv`, `ops.tsv`, `sums.tsv` are generated from the lists in `generate_vectors.py`; `--check` in `make lint` fails on drift. `currencies.tsv` is the source for the three built-in currency tables, and a test in each language fails if they differ. Version 0.1.0 agrees in `pyproject.toml`, `__init__.py`, `package.json`, `pom.xml` (`0.1.0-SNAPSHOT`). |
| 8 | Small changes, no secrets, validate input | pass | No secrets. Inputs validated at every entry point: literal text (regex, 400 characters, finite), amount text (regex with ASCII digits, 64 characters, scale), currency (known code, type), integers (Python rejects `bool`/`float`, JS accepts only `BigInt` or safe integers), repetition count (0..10,000,000), vector files (1 MB, column count, known name: `../secrets.tsv` is refused). No dependencies at runtime. |
| 9 | Tests that can actually fail | pass | No skipped or assertion-free tests (`grep -rnE "assert True|assertTrue\(true|@Disabled|skip|xfail|todo"` on the test folders finds nothing). Harness tests corrupt one expected value per vector file and require exactly one failure per suite; Python tests also swap in a broken `kahan_sum` and `ulp`. 14 hand mutations below, all killed. |
| 10 | Re-verify | pass | `.tmp/check.sh` twice: `vectors: 3 files up to date`; ruff clean; `mypy`: `Success: no issues found in 12 source files`; `pytest`: `161 passed`; `npm test`: `pass 117`, `fail 0`; `mvn verify` (`-Xlint:all -Werror`): `Tests run: 128, Failures: 0, Errors: 0, Skipped: 0`; pip-audit `No known vulnerabilities found`; npm audit `found 0 vulnerabilities`; `osv_audit.py Maven`: `8 dependencies checked, 0 with known vulnerabilities`; `CHECK PASS`. `audit_repo.py`: `floating-point-and-money: OK`. CI has not run yet (not pushed). |
